# 比赛提交证据目录

`final_environment_report.json` 和 `validation_result.json` 为当前本机执行结果。它们显示 SDK 文件可用，但授权、地图组件、插件宿主运行及业务分析尚未核验。`competition-scenario.template.json` 是真实案例来源与 MapGIS 图层绑定模板，`ready=false` 时不可宣称可运行。

成功运行评委演示后，程序才会在 `screenshots/demo-*/` 写入七张英文命名截图、补充封路截图及 `screenshots-manifest.json`；截图还需人工确认地图内容与属性。请勿向本目录放置合成的验收图片。
