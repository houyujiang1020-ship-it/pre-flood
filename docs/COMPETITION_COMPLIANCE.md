# 技术约束映射与未完成项

本文按用户提供的技术约束核对，不代表组委会已认可或软件已验收。

目标：MapGIS作为唯一GIS应用核心；PyTorch仅负责道路/建筑洪水状态智能感知。最终环境没有ArcGIS、SuperMap、QGIS、GeoServer、Leaflet、OpenLayers、Cesium、Mapbox或PostGIS GIS分析链。科研Rasterio仅在隔离训练环境。

已使用真实MapGIS JAR/Javadoc实现图层加载、栅格转换/空间参考、网络权/障碍/路径接口，已编译。授权尚未通过，不能声称这些功能已经成功运行。自写路由及合成PNG只作工程测试，不作为比赛GIS能力证据。

训练使用官方SpaceNet8公开样本，数据来源和CC-BY-SA-4.0说明保留；源代码上游Apache2.0锁定。不伪造checkpoint下载，不伪造模型精度。当前烟测权重IoU0，不能用于真实应急决策；flood_mask在烟测模型中仅为受淹建筑/道路并集，不是完整水面范围。

仍需授权后完成：插件现场加载、真实影像MapGIS配准、空间化位置验收、矢量化/叠加灾损、路段匹配、动态阻抗、安全路线、资源调度和真实结果报告完整链路。发布包明确标开发版，不把待办事项包装成参赛成品。
