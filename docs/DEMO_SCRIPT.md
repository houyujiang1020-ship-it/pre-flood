# 5–8分钟目标演示与当前边界

本流程是待实现的最终验收脚本，不是已成功演示的记录。

1. 0:00–1:00 打开MapGIS城市洪涝项目，展示官方影像和来源、道路/建筑/资源图层。
2. 1:00–2:00 选择两期配准影像和已评估模型，运行识别，说明性能与精度依据。
3. 2:00–3:00 展示MapGIS空间化结果及位置核验，计算实际面积、受灾建筑/道路与人口影响。
4. 3:00–4:30 选择受灾点，显示原始路线和阻断避让路线，说明路网单位和动态阻抗。
5. 4:30–6:00 推荐医院/消防/避难资源，比较容量、可达性和预计耗时。
6. 6:00–7:00 导出由真实分析结果和地图截图组成的灾情报告。

当前只能可信展示官方小样本训练、真实GPU推理和工程测试。MapGIS授权、空间业务闭环和精度未通过时，不使用演示数字或替代GIS引擎冒充完成。
