# 512 / 原生切片 / 1024 标签分辨率对照（2026-08-30）

实际证据：`experiments/diagnostics/reports/resolution_experiment.json`。运行入口为`app/training/diagnose_spatial_pipeline.py`，seed=20260830，从空间审计的随机顺序预先取每区前4组，共8组，不根据结果挑选样本。

比较A整图512、B原生网格上512不重叠窗口完整覆盖（边缘截短）、C整图1024。A/C是从同一3m缓冲矢量重新栅格化，符合当前训练实际，而不是先缩放二值mask。为比较形状，把A/C用nearest还原到原生网格计算road union的recall/IoU。面积比是同一tile CRS-grid单位面积之比，不把经纬度平方当平方米。此实验没有训练模型、没有推断高分辨率模型必然更准。

8组共38条道路要素，其中2条带受淹属性。三个尺度均没有完全消失的道路要素；512 road面积相对原生为99.9227%–100.1529%，1024为99.8772%–100.0615%。原生512窗口重新拼接后，8/8标签road像素完全保留（无插值，属于像素保真检查）。512还原后仍损失约3.0%–4.5%的原生道路像素，主要是边界栅格离散误差，1024降到约1.5%–2.2%。

在此可控小集，**不支持“整图512导致道路标签大量消失”是主要低精度根因**。保留约6m总宽的buffer使道路并非极端单像素细线。不能据8组/2条受淹路排除更小对象、短道路、其他地区、建筑细节或RGB纹理缩放损失；后者尚未做训练准确率对照。没有充分证据触发“因大量道路消失而立即强制替换正式训练”的条件。

下一步优先修正已经被强制过拟合/数据质量审计证实的管线风险，再以冻结train/validation比较原生tile与512；原生tile需要重新计算局部正类分组、有效mask和空间隔离，不能仅更改image_size即称实现了原分辨率滑窗训练。不要根据此处Louisiana研究样本的效果继续调参后声称独立测试。
